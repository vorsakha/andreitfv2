# Product

## Register

brand

## Users

Hiring managers, engineering leaders, developers, and collaborators evaluating Andrei's work. Public coding agents may also retrieve the same approved profile data through structured endpoints.

## Product Purpose

Present one accurate public identity for Andrei Ferreira as a full-stack software engineer with TypeScript, React, Node.js, NestJS, PostgreSQL, and developer-tooling depth. The site should make the work easy to understand, provide direct evidence, and expose a small read-only interface for machine clients.

Success means a person can understand Andrei's focus and strongest proof within one minute. Machine clients should retrieve the same intentionally public facts without scraping private or inferred information.

## Brand Personality

Calm, precise, self-possessed. The voice is direct and first-person. It favors concrete work over status language and leaves room for curiosity without performing cleverness.

## Anti-references

Do not resemble a generic portfolio template, startup landing page, AI workflow dashboard, developer terminal theme, or magazine layout. Avoid project-card grids, neon AI styling, gradients, glass panels, skill meters, oversized metrics, excessive animation, and ornamental technical diagrams. Do not reuse the old web2 and web3 positioning.

## Design Principles

- Lead with one clear thesis, then prove it with current work.
- Keep employer work and personal open-source work visibly separate.
- Let typography, spacing, and one authored line motif carry the identity.
- Use one bilingual, typed public source for human and machine views.
- Publish only facts that Andrei has intentionally approved for public use.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Maintain keyboard access, visible focus, readable contrast, semantic landmarks, descriptive link text, and a useful layout from narrow mobile screens through large desktops. Respect reduced-motion preferences. Color must never be the only carrier of meaning.
